        <h2>دليل تحميل وتثبيت محاكي xemu لتشغيل ألعاب Xbox الأصلي</h2>
        <p>لمحاكاة جهاز <b>Xbox الأصلي</b> على كمبيوترك والغوص في مكتبة ألعابه الأسطورية، فأنت بحاجة لمحاكي <b>xemu</b>، أحد أفضل المحاكيات المتوفرة حالياً. في هذا الموضوع، سنغطي لك كافة التفاصيل من التحميل إلى الملفات الأساسية.</p>
    </header>

    <section class="section-card">
        <h3>🚀 تحميل وتثبيت xemu حسب نظامك</h3>
        
        <h4>🪟 نظام Windows:</h4>
        <ul style="padding-right: 25px;">
            <li>🔗 <a href="#">xemu لـ Windows (x86_64)</a></li>
            <li>🔗 <a href="#">xemu لـ Windows (ARM64)</a></li>
        </ul>
        <p>بعد التحميل، فك الضغط وشغل <code>xemu.exe</code> مباشرة؛ لا يحتاج تثبيت تقليدي.</p>

        <h4>🍏 نظام macOS:</h4>
        <p>بعد فك الضغط، اضغط بزر الفأرة الأيمن واختر <b>Open</b> لتجاوز نظام الأمان، أو استخدم <code>Homebrew</code>:</p>
        <pre>brew install --cask xemu</pre>

        <h4>🐧 نظام Linux:</h4>
        <p><b>باستخدام AppImage:</b></p>
        <pre>chmod +x xemu.AppImage && ./xemu.AppImage</pre>
        <p><b>باستخدام Flatpak:</b></p>
        <pre>flatpak install -y app.xemu.xemu
flatpak run app.xemu.xemu</pre>
        <p><b>باستخدام Ubuntu PPA:</b></p>
        <pre>sudo add-apt-repository ppa:mborgerson/xemu
sudo apt update
sudo apt install xemu</pre>
    </section>

    <section class="section-card" style="border-right: 5px solid var(--xe-green);">
        <h3>📁 الملفات المطلوبة لتشغيل xemu</h3>
        <p>لكي يعمل المحاكي بكامل وظائفه، يجب عليك توفير 3 ملفات أساسية (تتحمل مسؤولية توفيرها بنفسك):</p>
        <ul style="padding-right: 25px;">
            <li>🔹 <b>MCPX Boot ROM:</b> رقم التحقق (MD5) الصحيح هو <code>d49c52a4102f6df7bcf8d0617ac475ed</code>.</li>
            <li>🔹 <b>Flash BIOS:</b> يجب استخدام نسخة Debug أو BIOS معدل مثل <b>COMPLEX 4627</b>.</li>
            <li>🔹 <b>Hard Disk Image:</b> صورة قرص Xbox وهمي جاهزة للتشغيل.</li>
        </ul>

        <h4 style="color: var(--xe-cyan); margin-top: 20px;">✅ خيارات القرص الصلب (HDD):</h4>
        <ul style="padding-right: 25px;">
            <li>🔗 <a href="#">تحميل قرص Xbox وهمي جاهز (8GB)</a></li>
            <li>📦 أنشئ قرصك المخصص باستخدام <b>FATXplorer</b>.</li>
            <li>🔁 انسخ قرص جهازك الأصلي باستخدام <b>XboxHDM</b>.</li>
        </ul>
    </section>

    <section class="section-card" style="border-right: 5px solid #fbc02d;">
