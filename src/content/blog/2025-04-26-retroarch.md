<h2>🛠️ الجزء الأول: تحميل وتثبيت RetroArch</h2>

<h3>مقدمة حول RetroArch</h3>

<p></p>RetroArch هو محاكي شامل متعدد الأنظمة، يسمح بتشغيل ألعاب العديد من المنصات الشهيرة. يتميز بكونه مفتوح المصدر ويدعم أنظمة Windows وLinux وmacOS وحتى الهواتف الذكية.<p></p>

<div class="notice">
📌 يدعم RetroArch مجموعة واسعة من الأجهزة، مثل Atari Lynx وNES وSNES وPlayStation 1 و2 وPSP وGameCube والعديد غيرها.
</div>

<h3>اختيار النسخة المناسبة</h3>

<p>عند زيارة <a href="https://www.retroarch.com/" target="_blank">موقع RetroArch الرسمي</a>، ستجد خيارين رئيسيين للتحميل:</p>

<ul>
<li>✅ النسخة المستقرة (Stable): تتميز بالثبات وخالية من الأخطاء.</li>
<li>🌙 النسخة الليلية (Nightly): تتضمن آخر الميزات ولكن قد تكون أقل استقرارًا.</li>
</ul>

<p>كما يمكن تحميل النسخة المحمولة (Portable) لمن يرغب بعدم التثبيت التقليدي.</p>

<div class="separator"></div>

<h3>طريقة تثبيت RetroArch</h3>

<p>بعد تحميل النسخة المناسبة، يتم تشغيل ملف التثبيت واتباع الخطوات التالية:</p>

<ul>
<li>الضغط على "التالي" والموافقة على الشروط.</li>
<li>تحديد مسار التثبيت (أو الإبقاء على الافتراضي).</li>
<li>تفعيل خيار تثبيت DirectX 9 إذا لم يكن مثبتًا مسبقًا.</li>
<li>إكمال التثبيت حتى النهاية.</li>
</ul>

<p>بعد انتهاء التثبيت، يُنصح بتغيير لغة الواجهة إلى الإنجليزية عبر:</p>

<p><b>Settings → User Interface → Language → English</b></p>

<div class="separator"></div>

<h2>🕹️ إعداد لوحة التحكم في RetroArch</h2>

<h3>🎮 أساسيات التنقل</h3>

<p>للتنقل داخل واجهة RetroArch:</p>

<ul>
  <li>✅ <b>الرجوع للخلف:</b> Backspace أو شعار البرنامج.</li>
  <li>✅ <b>الدخول للأقسام:</b> Enter أو الزر الأيسر للماوس.</li>
  <li>✅ <b>التنقل:</b> باستخدام الأسهم أو عجلة الماوس.</li>
</ul>

<h3>🎮 ضبط يد التحكم</h3>

<p>RetroArch يتعرف تلقائيًا على أيدي التحكم المتصلة، لكن في حال الحاجة لضبط يد التحكم يدويًا:</p>

<p><b>Settings → Input → Port 1 Controls → Set All Controls</b></p>

<h3>🎮 إعداد المفاتيح السريعة (Hotkeys)</h3>

<p>يمكن تخصيص المفاتيح السريعة عبر القائمة التالية:</p>

<p><b>Settings → Input → Hotkeys</b></p>

<div class="separator"></div>

<h2>🔹 تحميل الأنوية (Cores)</h2>

<p>لتحميل المحاكيات، يتم التوجه إلى:</p>

<ul>
<li>Main Menu → Online Updater → Core Downloader</li>
</ul>

<p>يمكن تحميل أنوية مثل:</p>

<ul>
<li>🕹️ Mupen64Plus (نينتندو 64)</li>
<li>🎮 Beetle PSX HW (بلايستيشن 1)</li>
<li>🐋 Dolphin (جيم كيوب ووي)</li>
<li>🎮 PCSX2 (بلايستيشن 2)</li>
</ul>

<p>ويُنصح أيضًا بتنزيل الملفات المساعدة عبر Core System Files Downloader.</p>

<div class="separator"></div>

<h2>📂 إعداد ملفات BIOS</h2>

<p>بعض المحاكيات تحتاج ملفات BIOS، توضع داخل:</p>

<p><b>RetroArch/system</b></p>

<p>ويُفضل إنشاء مجلد فرعي لكل محاكي لضمان تنظيم أفضل، مثل:</p>

<ul>
<li>📁 system/pcsx2/bios</li>
<li>📁 system/dc</li>
</ul>

<div class="notice">
⚠️ تأكد أن ملفات BIOS غير مضغوطة وبصيغتها الأصلية (.bin، .cue، .img).
</div>

<div class="separator"></div>

<h2>🎮 تشغيل الألعاب في RetroArch</h2>

<p>يمكن تشغيل الألعاب عن طريق:</p>

<ul>
<li>Main Menu → Load Content → اختيار اللعبة.</li>
<li>أو File → Load Content → تحديد المجلد المناسب.</li>
</ul>

<p>في حالة وجود أكثر من نواة تدعم اللعبة، سيُطلب تحديد المحاكي المناسب.</p>

<p>أثناء اللعب، يمكن فتح قائمة Quick Menu عبر الضغط على F1 لتغيير الإعدادات السريعة.</p>

<div class="separator"></div>
