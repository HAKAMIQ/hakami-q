    <h2 class="hakamiq-pads-title">🎮 دليل إعدادات وحدات التحكم لمحاكي RPCS3</h2>

    <p>يوفر محاكي RPCS3 دعماً واسعاً لمختلف وحدات التحكم، ولكن لضمان أفضل تجربة محاكاة (تحديداً لوظائف الحساسية والميلان)، يجب اختيار الوحدة المناسبة والتعريفات الصحيحة.</p>

    <hr class="hakamiq-divider" />

    <h3 class="hakamiq-section-header">💡 تحليل جودة وتوافق وحدات التحكم</h3>
    <div class="hakamiq-pads-box">
        <ul style="margin: 0; padding-right: 20px">
            <li><b>DualShock 3:</b> الوحدة الأصلية لجهاز PS3. تدعم حساس الضغط والميلان، ولكن توصيلها بالكمبيوتر يتطلب تعريفات خارجية دقيقة نظراً لتعقيد بروتوكولها.</li>
            <li><b>DualShock 4:</b> الخيار الأكثر استقراراً. تدعم الاهتزاز والميلان (Sixaxis) بشكل أصلي وتعمل بسلاسة عبر USB وبلوتوث.</li>
            <li><b>DualSense (PS5):</b> تدعم الوظائف الأساسية بكفاءة عالية، ولكن الميزات المتقدمة (Adaptive Triggers) غير مدعومة حالياً في المحاكي.</li>
            <li><b>Xbox / XInput:</b> تتميز بسهولة "التوصيل والتشغيل" الفورية، لكنها تفتقر تماماً لحساسية الضغط ووظائف الميلان الضرورية لبعض ألعاب PS3.</li>
        </ul>
    </div>

    <h3 class="hakamiq-section-header">🛠️ إعداد DualShock 3 على نظام Windows</h3>
    <p>تتوفر عدة خيارات لتثبيت التعريفات، ونرتبها حسب الأفضلية التقنية:</p>
    <div class="hakamiq-pads-box">
        <ol style="margin: 0; padding-right: 20px">
            <li><strong style="color: #00ffff">DsHidMini (الخيار الموصى به):</strong> تعريف حديث يدعم وضع البلوتوث والـ USB بكفاءة عالية ويحاكي سلوك اليد الأصلية.</li>
            <li><strong>تعريف سوني الرسمي:</strong> يدعم الاتصال عبر USB فقط، ولا يوفر ميزات البلوتوث.</li>
            <li><strong>ScpToolkit:</strong> تقنية قديمة لا يُنصح بها حالياً نظراً لعدم استقرارها وتعارضها مع وحدات XInput الأخرى.</li>
        </ol>
    </div>

    <div class="hakamiq-alert-red">
        <strong>⚠️ ملاحظات تقنية هامة:</strong>
        <ul style="margin-top: 5px">
            <li>يجب إزالة كافة التعريفات القديمة كلياً قبل تثبيت DsHidMini لتجنب تعارض النظام.</li>
            <li>الوحدات المقلدة (Third-party) غالباً ما تفشل في العمل مع التعريفات الرسمية.</li>
        </ul>
    </div>

    <h3 class="hakamiq-section-header">🔧 إعداد DualShock 4 و DualSense</h3>
    <p>على أنظمة Windows و Linux، يتم التعرف على هذه الوحدات بشكل أصلي. يُفضل استخدام <strong>Dedicated Pad Handler</strong> داخل إعدادات RPCS3.</p>
    <div class="hakamiq-alert-red" style="border-right-color: #ffb300; color: #ffb300; background: rgba(255, 179, 0, 0.05)">
        <strong>تنبيه:</strong> يجب إغلاق البرامج الوسيطة مثل (DS4Windows) قبل تشغيل المحاكي لتجنب تكرار المدخلات أو تضارب الأوامر.
    </div>

    <h3 class="hakamiq-section-header">🐧 إعدادات الأنظمة المتقدمة (Linux / FreeBSD)</h3>
    <p>يجب إضافة صلاحيات الوصول للوحدة عبر ملف <strong>udev rules</strong>. مثال لإعداد DualShock 3 عبر USB:</p>
    <div class="hakamiq-code-terminal">
        # DualShock 3 over USB<br>
        KERNEL=="hidraw*", ATTRS{idVendor}=="054c", ATTRS{idProduct}=="0268", MODE="0666"
    </div>
    <p>بعد الحفظ، يجب إعادة تحميل القواعد بالأمر التالي:</p>
    <div class="hakamiq-code-terminal">sudo udevadm control --reload-rules</div>

    <h3 class="hakamiq-section-header">🎯 تصحيح محاور الأنالوج (Analog Calibration)</h3>
    <p>في حال وجود انحراف في المحاور على أنظمة Linux، يمكن تعديل ملف الإعدادات يدوياً:</p>
    <div class="hakamiq-code-terminal" style="color: #ffd700">
        الملف: ~/.config/rpcs3/evdev_positive_axis.yml<br>
        تغيير القيم التالية إلى (true):<br>
        ABS_X: true | ABS_Y: true | ABS_RX: true | ABS_RY: true
    </div>
