<a class="ci-button ci-button-green" href="https://www.youtube.com/watch?v=PsWg6gqrxlk" rel="noopener noreferrer" target="_blank">
                مشاهدة الشرح
            </a>
</div>
</section>
<section class="ci-card">
<h3>مهم: الدليل القديم تغير</h3>
<p>
            الشرح الأصلي كُتب قبل إصدارات Cemu الحديثة. حاليًا المشروع يوفر
            Windows Installer ونسخة Portable، وLinux AppImage وFlatpak،
            ونسخة macOS تجريبية.
        </p>
<div class="ci-grid-2">
<div class="ci-mini">
<strong>Windows الحديث</strong>
                ما يحتاج ضبط High DPI يدويًا في كل الأجهزة. استخدمه فقط إذا
                ظهرت الواجهة ضبابية أو صغيرة أو غير متناسقة.
            </div>
<div class="ci-mini">
<strong>Linux الحديث</strong>
                ما تحتاج Lutris كطريقة أساسية؛ استخدم الإصدار الرسمي أو Flathub.
            </div>
</div>
<div class="ci-warning">
            لا تثبت Cemuhook مع Cemu 2.x لمجرد أن شرحًا قديمًا طلب ذلك.
            وظائف Graphic Packs وAssembly Patching موجودة داخل Cemu نفسه.
        </div>
</section>
<section class="ci-card">
<h3>متطلبات التشغيل الأساسية</h3>
<div class="ci-grid-3">
<div class="ci-mini">
<strong>النظام</strong>
                Windows أو Linux أو macOS بنظام 64-bit.
            </div>
<div class="ci-mini">
<strong>واجهة الرسوميات</strong>
<span class="ci-inline">Vulkan 1.2</span>
                أو <span class="ci-inline">OpenGL 4.5</span>.
            </div>
<div class="ci-mini">
<strong>الذاكرة</strong>
                4GB حد أدنى، و8GB أو أكثر أفضل.
            </div>
</div>
<div class="ci-note">
            حدّث تعريف كرت الشاشة قبل تثبيت المحاكي. Vulkan هو الاختيار الأفضل
            غالبًا، خصوصًا مع كروت AMD وIntel.
        </div>
</section>

<a class="ci-button" href="https://github.com/cemu-project/Cemu/releases/latest" rel="noopener noreferrer" target="_blank">

<section class="ci-card">
<h3>إعداد Portable على Windows</h3>
<div class="ci-step-grid">
<div class="ci-step-row">
<span class="ci-step-number">1</span>
<div class="ci-step-text">
                    فك ملف ZIP في مجلد مثل:
                    <span class="ci-inline">D:\Emulators\Cemu</span>.
                </div>
</div>
<div class="ci-step-row">
<span class="ci-step-number">2</span>
<div class="ci-step-text">
                    لا تستخدم <span class="ci-inline">Program Files</span>
                    أو أي مجلد يحتاج صلاحيات Administrator.
                </div>
</div>
<div class="ci-step-row">
<span class="ci-step-number">3</span>
<div class="ci-step-text">

                    <span class="ci-inline">portable</span>
                    بجانب ملف Cemu التنفيذي.

</div>
<div class="ci-step-row">
<span class="ci-step-number">4</span>

<section class="ci-card">
<h3>أخطاء شائعة من البداية</h3>
<div class="ci-grid-2">
<div class="ci-mistake">
<strong>التثبيت داخل Program Files</strong>
                يسبب مشاكل صلاحيات مع Portable والكتابة داخل المجلد.
            </div>
<div class="ci-mistake">
<strong>خلط الألعاب والتحديثات</strong>
                Game Path لازم يحتوي Base Games فقط.
            </div>
<div class="ci-mistake">
<strong>وضع MLC داخل Game Path</strong>
                يسبب فوضى في قائمة الألعاب وقد تظهر نسخ مكررة أو حمراء.
            </div>
<div class="ci-mistake">
<strong>تطبيق إعدادات DPI على الجميع</strong>
                لا تستخدمها إلا إذا ظهرت مشكلة Scaling فعلية.
            </div>
<div class="ci-mistake">
<strong>تفعيل جميع Graphic Packs</strong>
                فعّل ما تحتاجه فقط، وتأكد أن الحزمة مناسبة لكرتك وواجهة الرسوميات.
            </div>
<div class="ci-mistake">
<strong>استخدام دليل Cemuhook قديم</strong>
                Cemu الحديث ما يحتاج الإضافة للباتشات أو Graphic Packs.
            </div>
</div>
